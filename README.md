# CI/CD Demo Project 🔧

# О проекте

CI/CD Demo — демонстрационный проект, показывающий полный пайплайн непрерывной интеграции и доставки для Python-приложения с использованием современных инструментов DevOps.

# Архитектура проекта 🏗️

Проект состоит из следующих компонентов:

Python-приложение

Nginx-прокси

Система мониторинга

CI/CD инфраструктура

Управление секретами

# Установка и запуск 🎯

## Предварительные требования

Kubernetes кластер

Helm

Docker

Git

# Инструкция по установке

## bash
### Клонирование репозитория
`git clone https://github.com/islamovdanil/ci-cd-demo`
`cd ci-cd-demo`

### Сборка Docker-образа
`docker build -t ci-cd-demo .`

### Установка Helm-чарта
`helm repo add local ./charts`

`helm install ci-cd-demo local/ci-cd-demo`

# Основные компоненты 🏢

Python-приложение

main.py — основной код приложения

metrics.py — сбор метрик

requirements.txt — зависимости

# Инфраструктура

Dockerfile — конфигурация контейнера

nginx.conf — настройки прокси-сервера

vault-secrets.py — интеграция с Vault
